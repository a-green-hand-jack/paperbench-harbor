# Upstream agent instructions (PaperWrite-Bench)

The files in this directory are the benchmark instructions that PaperRecon
hands to its writing agents per paper type (`AGENTS_<type>.md`, delivered to
the agent as `CLAUDE.md` or `AGENTS.md`). They were copied unmodified from
`Agent4Science-UTokyo/PaperRecon` (Apache-2.0,
`paper_recon/writing/agents_md/`) so that Harbor tasks preserve the exact
upstream instruction surface.

- `AGENTS_method.md` — papers of type `method`
- `AGENTS_benchmark.md` — papers of type `benchmark`
- `AGENTS_both.md` — papers of type `both`
